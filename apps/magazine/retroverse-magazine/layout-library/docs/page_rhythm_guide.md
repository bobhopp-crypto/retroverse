# RetroVerse Page Rhythm Guide

## Core Principle
RetroVerse should read like a mixtape, not a textbook. A strong issue alternates visual density and reading effort so the reader keeps momentum.

Magazine rhythm is built by contrast:
- Big visual opener
- Text-heavy interpretation page
- Collage interruption
- Sidebar-driven department page
- Data/chart analysis page
- Comic or parody release page

If every page has identical density, the issue feels flat. If every page is maximal, the issue feels noisy. Rhythm comes from deliberate alternation.

## Practical Rhythm Rules
1. Follow dense pages with visual relief.
2. Place at least one high-energy visual format every 4-6 pages.
3. Do not chain three text-heavy pages without a reset page.
4. Use chart/data pages as analytical pivots between narrative sections.
5. Place comic/parody pages where the reader needs tonal oxygen.
6. Use back page as a strong visual landing, not another essay.

## Recommended Visual Density Tags
- **Low text / high visual:** cover, collage, parody, back page
- **Balanced:** feature spread, data page, contents page
- **High text / moderate visual:** department column, editorial analysis

## Example Sequence: 24-Page Issue
Use this as a baseline rhythm map.

1. Cover (big visual)
2. Contents (navigation + collage)
3. Editorial (text-led)
4. Feature spread part 1 (balanced)
5. Feature spread part 2 (text-led)
6. Grid collage (visual reset)
7. Department column (text-led)
8. Data/charts page (analytical pivot)
9. Feature continuation (balanced)
10. Sidebar-heavy quick reads (light text chunks)
11. Visual parody page (humor reset)
12. Department column (text-led)
13. Illustration grid (visual)
14. Debate/interview page (balanced)
15. Data/charts follow-up (balanced)
16. Comic page (sequential visual)
17. Music department (text-led)
18. Culture notebook collage (visual)
19. Advice column (text-led)
20. Artifact timeline page (balanced)
21. Critic roundtable (text-led)
22. Poster-style feature image (visual)
23. Closing note (short text)
24. Back page (strong finish visual)

## Example Sequence: 48-Page Issue
Longer issues should use repeating rhythm arcs.

Arc A (pages 1-12): establish tone
- Cover, contents, editorial, lead feature, feature continuation, collage, department, data page, feature close, sidebar page, parody, department

Arc B (pages 13-24): deepen core themes
- Grid collage, interview, data page, comic page, columnist page, artifact page, feature spread, debate page, chart page, parody, short essays, back-half opener visual

Arc C (pages 25-36): broaden cultural range
- TV/film column, collage, music analysis, timeline page, comic, department, data page, artifact spread, parody ad page, critic notes, mini profile, visual reset

Arc D (pages 37-48): close with momentum
- Long-form feature, chart page, letters page, collage, advice, comic, parody, culture forecast, short editorial, poster page, final note, back page

## Sequence Checklist for Editors and Builders
Before locking an issue sequence, verify:
- No run of more than two pages with identical structure.
- At least one visual reset every 4-6 pages.
- Data pages are placed at turning points, not random positions.
- Comic/parody moments are intentional tone shifts.
- Final three pages feel like a closing arc, not leftover modules.

When in doubt, adjust rhythm by swapping template types before rewriting copy.
