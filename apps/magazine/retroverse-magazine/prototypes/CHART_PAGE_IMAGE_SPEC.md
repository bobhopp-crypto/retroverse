# Chart Page Image Spec (LOCKED)

## Output Size

- **Pixels:** 2850 × 3600
- **Orientation:** Portrait (vertical)
- **Print size:** 9.5in × 12in at 300 DPI

## Rules

- Always generate in portrait
- Never generate landscape
- Never generate two-page spreads
- Composition must fill the entire page
- Single page only

## Usage

All chart page layout images must use this size. Resize output to 2850×3600 if the generator produces a different size.
